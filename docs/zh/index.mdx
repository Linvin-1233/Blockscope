## 欢迎使用 Blockscope

**Blockscope** 是一个用 Rust 编写的离线、独立 Minecraft 投影文件检查与渲染引擎。它将 `.litematic` 文件转换为 Scene IR，生成纯色方块或带材质网格（OBJ/PLY），并在 CPU 或可选离屏 GPU 后端上生成正交 PNG，还可通过外部 ffmpeg 导出关键帧 MP4/GIF。无需运行中的 Minecraft 客户端。

## 核心能力

<Steps>
  <Step title="1. 容器解析（阶段 1）">
    流式、内存受限的 NBT 读取器，可解析 `.litematic` 文件（v1 至 v7）。重建区域层级、解析调色板，并将方块状态规范化为可查询的 `Scene`。
  </Step>
  <Step title="2. 网格几何（阶段 2）">
    将场景几何分页为 16³ 体素区块，自动执行面剔除、平滑环境光遮蔽（AO）与四边形去重，并导出为标准 Wavefront OBJ 与 Stanford PLY。
  </Step>
  <Step title="3. 光栅化（阶段 3）">
    分块软件光栅化器将内置纯色方块调色板或官方 Java 资源包材质渲染为抗锯齿正交 PNG。可选离屏 `wgpu` 后端复用同一套场景与网格管线；CPU 仍是逐字节参考。
  </Step>
  <Step title="4. 服务协议（阶段 4）">
    基于 stdio JSONL 协议 v4 的隔离式单任务 worker（`serve` / `supervise`）、supervisor 进程管理、图片与视频任务，以及可预期的错误处理。
  </Step>
  <Step title="5. 视频导出">
    关键帧相机时间线通过外部 ffmpeg 4.4+ 导出 MP4 或 GIF，可使用 CPU 或 GPU 帧会话，并可选硬件编码。
  </Step>
</Steps>

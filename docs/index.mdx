## Welcome to Blockscope

**Blockscope** is an offline, standalone Minecraft schematic inspection and rendering engine written in Rust. It turns `.litematic` files into Scene IR, generates color-block or textured meshes (OBJ/PLY), and produces orthographic PNG renders on the CPU or an optional offscreen GPU backend, plus keyframed MP4/GIF clips through an external ffmpeg. It does not require a running Minecraft client.

## Core Capabilities

<Steps>
  <Step title="1. Container Parsing (Phase 1)">
    Streaming, memory-bounded NBT reader capable of parsing `.litematic` files (v1 through v7). Reconstructs region hierarchy, resolves palettes, and normalizes block states into a queryable `Scene`.
  </Step>
  <Step title="2. Mesh Geometry (Phase 2)">
    Paginates scene geometry into 16³ voxel chunks with automatic face culling, smooth ambient occlusion (AO), and quad deduplication. Exports to standard Wavefront OBJ and Stanford PLY.
  </Step>
  <Step title="3. Rasterization (Phase 3)">
    Tiled software rasterizer producing anti-aliased orthographic PNGs from built-in color-block palettes or official Java resource-pack textures. An optional offscreen `wgpu` backend shares the same scene and mesh pipeline; the CPU remains the byte-exact reference.
  </Step>
  <Step title="4. Service Protocol (Phase 4)">
    Single-job worker isolation with stdio JSONL protocol v4 (`serve` / `supervise`), supervisor process management, image and video jobs, and predictable error handling.
  </Step>
  <Step title="5. Video Export">
    A keyframed camera timeline renders MP4 or GIF through an external ffmpeg 4.4+ executable, with CPU or GPU frame sessions and optional hardware encoding.
  </Step>
</Steps>
